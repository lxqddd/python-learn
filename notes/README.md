# 📓 笔记目录

把每天的学习笔记按下面结构归档：

```
notes/
├── README.md            ← 本文件
├── week1/               ← 第 1 周：概念 + 环境
│   ├── day1-concepts.md
│   └── day2-tool-design.md
├── week2-3/             ← 第 2-3 周：Python 基础
│   └── ...
├── week4/               ← 第 4 周：First 7 Days Sprint
│   └── ...
└── insights/            ← 跨周的灵感、踩坑、顿悟
    └── yyyy-mm-dd-xxx.md
```

## 📝 笔记模板

每个笔记文件建议包含：

```markdown
# 日期 · 主题

## 今天学到了什么（3 条以内）

## 踩过的坑

## 明天要做什么
```

## 💡 原则

- **用自己的话重写概念**（不要复制粘贴）
- **记命令**（git / curl / Python 一行）
- **画图**（架构、流程、数据流）
- **写问题**（不懂的列出来，下次问 AI）
