## 🚀 使用方法

1. **找到今天的文件**：根据当前周次 + 星期打开对应文件
2. **逐项完成 checkbox**：把 `[ ]` 改成 `[x]`
3. **更新进度条**：在文件末尾根据勾选数量更新
4. **周末做周验收**：打开 `W{周}-review.md`
