## ✅ 任务清单（2h）

### 🎬 项目 1 视频（40min）

- [ ] **[10min]** 准备大纲（STAR 法则）：
  - **S**ituation：场景（"用户上传 PDF 想对话式问答"）
  - **T**ask：任务（"端到端 RAG + Agent 系统"）
  - **A**ction：行动（架构分层 + 关键技术选型）
  - **R**esult：结果（量化指标：30 eval / RAGAS 0.87 / P99 480ms / 上线 demo）
- [ ] **[20min]** 对着手机/屏幕录视频，**5 分钟内讲完**（不要超时）
- [ ] **[10min]** 自己回看 → 卡的地方重录 → 至少录 3 遍

**5 分钟脚本模板**：
```
0:00-0:30  项目是做什么的（一句话）
0:30-1:30  为什么用 Agent 而不是 workflow
1:30-2:30  架构图（分层画）
2:30-3:30  3 个关键技术决策（为什么 LangGraph / 为什么 Chroma / 为什么 MCP）
3:30-4:30  量化结果（成功 % / 延迟 / 成本）
4:30-5:00  学到了什么 + 下一步
```

### 🎙️ 八大组件录音（40min）

- [ ] **[40min]** 对着 Agent 八大组件（来自 `docs/concept-notes.md`），每个组件录 1 分钟解释：
  1. Goal — 任务 + 成功标准
  2. Policy — 系统约束 + 安全规则
  3. State — 当前进度 + 历史
  4. Memory — 可复用经验 + 用户偏好
  5. Context Builder — 组装模型输入
  6. Tool Registry — 声明可调用工具
  7. Loop Controller — 决定下一步 + 停止条件
  8. Eval / Trace — 记录 + 评估行为

**录音要点**：每个组件说清"是什么 / 解决什么问题 / 我的项目怎么用"。
