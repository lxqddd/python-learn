  ```markdown
  # 个人知识库助手 · 需求文档
  
  ## 用户场景
  - 目标用户：研究人员 / 律师 / 医生 / 学生
  - 核心痛点：本地有大量 PDF/Markdown 笔记，找信息困难
  
  ## 功能列表
  ### MVP
  - [ ] 上传 PDF / Markdown 文件
  - [ ] 自动切片 + 向量化
  - [ ] 对话式问答
  - [ ] 引用原文出处
  - [ ] 多轮对话记忆
  
  ### 非目标
  - ❌ 多模态
  - ❌ 协作
  - ❌ 实时联网搜索
  
  ## 成功标准
  - 用户上传 PDF 后能问到答案
  - 答案含引用（页码）
  - P99 延迟 < 2 秒
  - 30 条 eval case 通过率 > 80%
  ```
